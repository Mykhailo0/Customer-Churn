# Customer Churn MLOps

## Опис проєкту

Проєкт призначений для прогнозування відтоку клієнтів (Customer Churn) за допомогою машинного навчання. Він містить етапи перевірки якості даних, створення версії датасету, навчання моделі та оцінювання її якості.

## Структура проєкту

- `configs/data_schema.yaml` — схема та правила перевірки даних.
- `data/raw/churn.csv` — початковий датасет.
- `data/processed/churn_v1.csv` — перевірена версія датасету `v1`.
- `src/validate_data.py` — скрипт валідації даних.
- `src/version_data.py` — скрипт створення версії датасету.
- `src/data_preparation.py` — підготовка ознак для моделі.
- `src/train.py` — навчання моделі та обчислення метрик.
- `reports/data_validation_report.json` — звіт про якість даних.
- `reports/baseline_metrics.json` — метрики навченої моделі.
- `models/baseline_model.joblib` — збережена модель машинного навчання.

## Встановлення залежностей

Активуйте віртуальне середовище та встановіть необхідні бібліотеки:

```bash
pip install -r requirements.txt
```

## Валідація даних

Для запуску перевірки якості початкового датасету виконайте команду з кореневої папки проєкту:

```bash
python src/validate_data.py
```

Скрипт перевіряє:
- наявність обов'язкових стовпців;
- наявність дублікатів;
- частку пропущених значень;
- допустимі значення цільової змінної `Churn`;
- коректність значень у числових стовпцях.

Результат перевірки записується у файл `reports/data_validation_report.json`.

### Значення статусів

- **passed** — перевірку пройдено: критичних помилок за визначеними правилами не виявлено.
- **failed** — перевірку не пройдено: виявлено помилки, які потребують виправлення.

Дублікати фіксуються як попередження, а не як критична помилка. Якщо валідація завершується зі статусом `failed`, скрипт повертає ненульовий код завершення.

## Версіонування даних

Для створення версії датасету виконайте:

```bash
python src/version_data.py
```

Перевірена версія `v1` зберігається у файлі:

`data/processed/churn_v1.csv`

Скрипт формує метадані версії, зокрема:
- ідентифікатор версії;
- шлях до початкового та вихідного файлів;
- SHA-256 хеші файлів;
- дату створення;
- кількість рядків і стовпців.

## Навчання моделі

Для навчання моделі та обчислення метрик виконайте:

```bash
python src/train.py
```

Модель навчається на версії датасету **`v1`**, розташованій за шляхом `data/processed/churn_v1.csv`.

Результати оцінювання записуються у файл `reports/baseline_metrics.json`. Звіт містить поле `data_version`, яке вказує версію даних, використану для навчання.

Основні метрики:
- `accuracy` — частка правильних прогнозів;
- `precision` — точність позитивних прогнозів;
- `recall` — повнота виявлення клієнтів, які можуть піти;
- `f1` — гармонічне середнє precision і recall;
- `roc_auc` — здатність моделі розрізняти два класи.
