Customer Churn MLOps

Мета проєкту

Метою проєкту є розробка базового MLOps-рішення для прогнозування відтоку клієнтів (Customer Churn). Система виконує підготовку даних, навчання моделі машинного навчання, оцінювання її якості та збереження результатів.

Джерело даних

Для навчання використано набір даних Telco Customer Churn. Датасет містить інформацію про клієнтів телекомунікаційної компанії та цільову колонку Churn, яка визначає, чи залишив клієнт компанію.

data/raw/churn.csv

Встановлення залежностей

Для встановлення необхідних бібліотек використовується команда:

pip install -r requirements.txt

Основні бібліотеки проєкту:

pandas;

scikit-learn;

joblib;

pytest.

Запуск навчання

Для запуску підготовки даних та навчання базової моделі необхідно виконати:

python src/train.py

Після успішного виконання модель зберігається у:

models/baseline_model.joblib

Метрики моделі зберігаються у:

reports/baseline_metrics.json

Отримані метрики

У результаті навчання базової моделі Logistic Regression були отримані такі метрики:

Accuracy: [ 0.7637]
Precision: [ 0.7303]
Recall: [0.1738]
F1-score: [ 0.2808]
ROC-AUC: [0.8195]

Короткий висновок

У межах лабораторної роботи було створено базовий MLOps-проєкт для прогнозування відтоку клієнтів. Було виконано завантаження та підготовку даних, перетворення цільової змінної, кодування категоріальних ознак та навчання моделі Logistic Regression. Модель була оцінена за основними метриками класифікації, а сама модель і результати оцінювання збережені у відповідних директоріях проєкту. Отриманий результат може використовуватися як базова модель для подальшого вдосконалення системи та порівняння з іншими алгоритмами.
